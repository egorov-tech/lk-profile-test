# Личный кабинет — окно «Мой профиль»

## Цель

Собрать самостоятельное тестовое окно личного кабинета с адаптацией desktop/mobile, которое можно запустить как Vite-приложение и встроить в Laravel через Vite.

## Решение

Выбран экран «Мой профиль»: навигация по кабинету, верхняя панель, форма личных данных и блок безопасности. Он покрывает основной набор интерфейсных паттернов ЛК: навигацию, поля ввода, действия, уведомление об успехе и mobile-menu.

## Технические ограничения

- Vue 3, Composition API только через `<script setup>`.
- Каждый переиспользуемый компонент расположен в отдельном `.vue` файле и содержит менее 300 строк.
- Имена Vue-файлов начинаются с `account_` и описывают назначение.
- Нет inline CSS и обработчиков DOM-событий в разметке HTML вне Vue-шаблонов.
- Стили вынесены в CSS-файлы; компонентные классы имеют префикс `account-`.
- Страница готова к `@vite('resources/js/app.js')`; Laravel передаёт начальные данные через `window.__ACCOUNT_PROFILE__` или props при дальнейшем подключении.

## Адаптация

- Desktop: постоянный sidebar и двухколоночная верхняя панель.
- До 900px: sidebar заменяется кнопкой меню и off-canvas навигацией.
- До 560px: одна колонка формы, полноширинная кнопка сохранения, удобные tap-targets не менее 44px.

## Проверка

- Unit-тесты: кнопка корректно эмитит событие, инпут работает с `v-model`, страница показывает toast после сохранения.
- Production-сборка Vite.
- Ручная проверка экранов 1440px, 768px и 390px.
